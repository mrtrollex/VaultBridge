    About VaultBridge
    
          
    
        
    
        
    
          
    VaultBridge is a self-hosted REST and semantic retrieval bridge for Obsidian vaults.
    
          
    It keeps durable knowledge in Markdown while giving trusted clients a small, stable access layer.
    
        
    
        
    
          
    
            
    Local first
    
            
    Your vault stays usable on its own.
    
            
    Markdown remains the source of truth, and semantic data can be rebuilt from it.
    
          
    
          
    
            
    API first
    
            
    One interface, many clients.
    
            
    The dashboard, scripts, AI clients, and other integrations use the same protected API.
    
          
    
          
    
            
    Self hosted
    
            
    Knowledge stays under operator control.
    
            
    VaultBridge runs beside the vault and uses local embeddings by default.
    
          
    
          
    
            
    Deliberately small
    
            
    Access without replacing Obsidian.
    
            
    Retrieval and safe note operations extend the vault without turning it into a proprietary store.
