# Jellyfin Media Library

## Library Backup

Back up Jellyfin posters, subtitles, playlists, and media-library metadata with a retention policy. Restore the media catalog after an upgrade without confusing it with a database or NAS dataset backup.

## Transcoding

Jellyfin transcodes movie and audio streams for client devices. Hardware acceleration, codecs, subtitle rendering, and temporary storage affect playback performance.
